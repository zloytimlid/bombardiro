# Реестр ассетов

Каждый ассет проекта: путь, источник, лицензия, атрибуция. Таблица ниже — единственный источник: её же показывает
страница «О проекте» (`/about`), а тест `tests/Feature/AssetsRegistryTest.php` проверяет, что у каждого файла ассетов
в репозитории есть строка. Чужие защищённые ассеты (модели, звуки, логотипы) запрещены.
Персонаж Li'l Abner не воспроизводится — слот `nose_art` (рисунок даёт заказчик, см. `resources/images/nose-art/README.md`).

Музыка главного меню — файлы в `resources/audio/menu/` (подхватываются автоматически, в репозиторий не коммитятся без строки
здесь). Только собственные треки или с открытой лицензией (CC0, CC BY с атрибуцией). Рисунок на носу —
`resources/images/nose-art/` по той же схеме.

Библиотеки (Three.js, Vue, Laravel и др.) — не ассеты: их лицензии — в `composer.lock` / `package-lock.json`.
