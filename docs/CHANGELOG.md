## [Unreleased]

### Fixed
- Смена хоста под нагрузкой: тишина хоста считается по времени прихода запросов в nginx, сервер дожидается порога
  в запросе `host-lost` (до 1,2 с), первый хост получает льготный срок 5 с на загрузку мира — роль больше не «скачет».
- Локальная среда: Vite опрашивает файлы раз в секунду и не следит за `app/`, `config/`, `docker/` и т. п. (опрос
  каждые 300 мс через 9P-сервер Docker Desktop занимал 1,5–2,5 ядра); зависимости игры собираются при старте Vite
  (`optimizeDeps.include`) — без перезагрузки вкладок посреди вылета; права на `storage/` выставляет entrypoint.
- E2E на Windows рисует WebGL видеокартой (ANGLE/D3D11) вместо SwiftShader.
- Музыка главного меню в разработке: CSP `media-src` не пускала файлы с сервера Vite (`localhost:5173`).

### Added — этап 6, расширения
- Повторы вылетов: после разбора задача `BuildReplay` кладёт в S3 `replays/{ulid}.json.gz` (миссия, версия, сид,
  журнал, трек — мир детерминирован по сиду); `GET /api/sessions/{ulid}/replay` — участникам, закрепление
  `POST …/replay/pin` — хосту, владельцу экипажа, админу; незакреплённые удаляет `PurgeOldReplays` через 30 дней.
  Кнопки «Скачать» и «Закрепить» на странице разбора.
- Кампании (`campaigns`, `campaign_progress`, каталог `resources/sim/campaigns/`): экипаж записывается в лобби, борт
  переносит повреждения зон между вылетами, ремонт — день (доля прочности из `rules.repair_per_day`, gameplay),
  возвращение — шаг вперёд, неудача — повтор миссии; `ComputeDebrief` записывает итог.
- Генератор вылетов (раздел 8.5): `generateMission` в симядре — цель из пула театра (`mto-west.generator`), маршрут
  в обход известных зон ПВО и над рельефом, погода по месяцу, ПВО и истребители по сложности; детерминирован по сиду.
  Форма на странице миссий, `POST /api/missions/generated` проверяет миссию той же схемой и хранит черновиком игрока
  (`missions.generated_by`, виден только ему и его экипажам).
- Звено до 4 экипажей (`flights`): ведущий создаёт звено, остальные входят по коду, старт ведущим — все экипажи сразу
  с общим сидом и интервалом взлёта 35 с; хосты экипажей обмениваются положением в `presence-flight.{flight}` (5 Гц),
  другие борта звена рисуются в мире.
- Голосовое СПУ (WebRTC, сигнализация whisper `rtc` в канале вылета): по тангенте (по умолчанию N), «радиофильтр»
  на приёме; ICE-серверы — `VOICE_ICE_URLS` (без TURN за симметричным NAT связь может не установиться).
- Рендер WebGPU по настройке «Рендер» (`renderer: webgpu`), при отсутствии поддержки — WebGL 2.

### Added — этап 5, полировка и запуск
- Настройки игры `/settings/game` и `GET/PUT /api/me/settings` (`UserSettingsData` — одна схема для сервера и клиента):
  переназначение клавиш и кнопок геймпада (захват нажатием, подсветка конфликтов), оси геймпада/HOTAS с мёртвой зоной
  и кривой, РУД HOTAS, наведение пулемёта правым стиком; чувствительность и инверсия мыши; пресет графики и масштаб
  рендера; громкость по категориям; доступность — субтитры СПУ, отключение тряски камеры, масштаб интерфейса 80–150 %,
  удержание или переключение для длительных действий, единицы.
- Вход через Discord и Google (Socialite, ADR-0008): `social_accounts`, связка по почте, позывной из ника; без ключей — нет кнопок.
- Модерация в `/admin`: игроки (роль, блокировка с причиной — `EnsureNotBanned` выходит из аккаунта), вылеты с флагами
  (принять в рейтинг / отклонить, кто и когда решил).
- Персональные данные: выгрузка `GET /api/me/export`, удаление аккаунта стирает данные и обезличивает участие в вылетах
  (экипаж и его вылеты остаются у остальных; владелец экипажа — `null`).
- Безопасность: `SecurityHeaders` — CSP с nonce (встроенный скрипт темы), только свой домен, `frame-ancestors 'none'`,
  `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`, HSTS в продакшене; тесты чек-листа раздела 13.
- Наблюдаемость: Sentry сервера и клиента без PII (ADR-0006), Pulse с карточками Reverb и клиентской телеметрии
  FPS/RTT (`POST /api/telemetry`, ADR-0007), JSON-журналы с `flight_session_id` (`LOG_CHANNEL=json`, `LogContext`).
- Планировщик: `PurgeOldEvents` (журнал — 90 дней), `CloseStaleCrews` (брошенные лобби и вылеты, каждые 15 минут).
- Продакшен: стадии `prod` и `web` в `docker/php/Dockerfile`, `compose.prod.yaml` (Caddy с TLS, Reverb, Horizon,
  планировщик, резервные копии в S3 с проверкой восстановления), `.dockerignore`; ранбук `docs/ops.md`.
- Бюджет бандла в CI (`npm run budget:bundle`): весь JS сборки — 0,55 МБ gzip при пределе 1,5 МБ.

### Added — этап 4, контент MVP
- Театр `mto-west` — Корсика, юг Франции и север Италии: рельеф по грубой береговой линии, осям хребтов (Альпы,
  Апеннины, Центральный массив, Прованс), долинам (Рона, Дюранс, По, Адидже, Изарко, Инн) и перевалам (Бреннер, Чиза);
  сетка расстояний до берега считается при запуске (~0,6 с), высота — билинейно + шум (`GeoTerrain`, `createTerrain`).
- Миссии «Авиньон» (железнодорожный мост через Рону, сложность normal) и «Бреннер» (мост линии Бреннера в долине Адидже,
  hard) — «по мотивам», `placeholder: true`; маршруты проверены тестом на запас над рельефом, время над целью — по прогону ИИ.
- ИИ: при возврате до цели — домой обратным путём по пройденным точкам (`reroute_home`, входит в снапшот миграции),
  аварийный сброс бомб на одном двигателе, пилот держит высоту не ниже рельефа впереди + 500 м.
- Итоговая процедурная модель B-25J: тело вращения фюзеляжа, крыло «чайка», мотогондолы с капотами и патрубками,
  овальные кили, остекление с переплётом, турели; ливрея оливковый верх / серый низ, опознавательные знаки ВВС США,
  надпись и код из конфигурации борта; слот `nose_art` подхватывает картинку из `resources/images/nose-art/`.
- Звук (WebAudio, без файлов): двигатели по оборотам и наддуву с панорамой по станции, поток, пулемёты, разрывы зениток
  с задержкой по расстоянию, рация на фразах СПУ; категории громкости хранятся в браузере.
- Достижения (`achievements`, `user_achievements`, каталог `resources/sim/achievements.json` с декларативными условиями),
  задача `AwardAchievements` (статистика профиля + достижения, один раз на вылет), событие `DebriefReady`.
- Ангар `/hangar` (профиль, налёт, достижения, история вылетов), рейтинги `/leaderboards` и `GET /api/leaderboards`
  (только проверенные вылеты, по миссии и периоду).
- Страница «О проекте» `/about` с атрибуциями из `docs/assets.md`; собственный значок проекта вместо логотипа стартового кита.
- Переводы: все строки интерфейса (вход, регистрация, настройки, 2FA, ключи доступа, меню) — через ключи;
  русские сообщения проверки ввода `lang/ru/validation.php`; автопроверка ключей и «зашитых» строк (`resources/js/i18n.test.ts`).
