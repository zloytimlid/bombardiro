## [Unreleased]

### Added — этап 2, все станции в одиночной игре
- Контент: `resources/sim/weapons/m2.json` (баллистика, перегрев, задержки), `weapons/bombs.json` (AN-M64, AN-M65),
  `enemies/fighters.json` (Bf 109 G, Fw 190 A, уровни пилотов), `enemies/flak.json` (тяжёлая и малокалиберная ЗА);
  в `b25j.json` — зоны повреждений раздела 7.3, сектора и зоны запрета огня установок, точки глаз 8 станций, кислород.
- Формат миссии (раздел 8.3) — zod в ядре → `resources/sim/schemas/mission.schema.json`; обучающая миссия
  `resources/sim/missions/milk-run.json` («по мотивам», `placeholder: true`). На театре Корсики — условный берег материка.
- Мир вылета `MissionWorld`: 9 фаз вылета, триггеры «условие → действие», ведомые в строю, ускорение ×2/×4 на маршруте.
- Повреждения: рейкаст пуль по коробкам зон, осколки зениток по видимой площади, подсистемы и их эффекты
  (отказ прицела, приборов, люка, турели, радио; утечки и протектор баков; масло → заклинивание; пожары двигателя,
  крыла и фюзеляжа с таймером разрушения; асимметрия подъёмной силы, потеря элерона и рулей; разбитое шасси; гидравлика).
- Экипаж: ранения (лёгкое/тяжёлое), первая помощь, гипоксия, задачи бортинженера, передача управления второму пилоту,
  покидание самолёта, СПУ с каталогом фраз, круговой индикатор угроз по часовой системе.
- Пулемёты M2: сектора, скорость наведения, трассеры, боезапас, перегрев, задержки; прицел-упреждение.
- Зенитки: упреждённая точка, ошибка падает на прямом курсе и сбрасывается при манёвре, заградительный огонь.
- Истребители: «патруль → обнаружение → сближение → заход (в лоб, сверху сзади, с борта) → выход → повтор/уход», облака.
- Бомбометание: баллистика бомб с сопротивлением и ветром, баллистические таблицы, игровой тахометрический прицел
  (ручки «скорость»/«снос», перекрестье, автоматический сброс, серия/залп, интервалометр, PDI), поражение моста по пролётам.
- Навигация: счисление, визир сноса, ветровой треугольник, курс с поправкой на ветер, отметки по ориентирам,
  радиокомпас, расчёт времени над целью. Радио: настройка по шуму, приём, кодовая таблица дня, «свой-чужой», бедствие.
- ИИ-экипаж на всех 8 станциях (уровни «новичок / опытный / ветеран») теми же командами, что и игрок.
- Разбор: итог экипажа (цель, самолёт, экипаж, время над целью), метрики всех станций раздела 6, трек, таймлайн,
  схема разрывов. Тренировки всех 8 станций с оценкой 0–100.
- Клиент: переключение станций 1–8, камеры и экраны каждой станции (кабина, окуляр прицела, планшет штурмана,
  панель радиста, пулемёты в Pointer Lock с кольцевым прицелом и маркером упреждения в «Учебном»), колесо СПУ (Q),
  общий оверлей, брифинг и разбор; рельеф следует за камерой; ведомые, истребители, разрывы, трассеры, бомбы, мост.
- Сервер: таблица `missions` (версии, публикация), `ImportMission` (JSON Schema + laravel-data, ADR-0004),
  `sim:sync` грузит миссии; `/missions`, `/missions/{slug}/solo`, `GET /api/missions[/{slug}]`; тренировки всех станций.
- Тесты: юнит-тест баллистики «4000 м, идеальная синхронизация — промах ≤ 30 м», тест на каждую строку таблицы 7.3,
  прогон «все 8 — ИИ» от запуска до посадки, тренировки 8 станций, детерминизм мира; Pest для миссий;
  E2E «один игрок: брифинг → вылет → разбор».

### Added — этап 1, симядро и полёт пилота
- `resources/sim/aircraft/b25j.json` по шаблону 16.1 + калиброванная аэродинамика и модель двигателя;
  zod-схема в ядре и сгенерированная `resources/sim/schemas/aircraft.schema.json`.
- Симядро `resources/js/sim/core` (чистый TS): 6DOF твёрдого тела 60 Гц, МСА, ветер по слоям и сид-турбулентность,
  CL(α, закрылки) со сваливанием и асимметрией, CD с шасси/люком/закрылками, экранный эффект, моменты с демпфированием;
  двигатели: наддув по высоте, регулятор оборотов, мощность, ГЦ, износ, флюгирование, авторотация, запуск конечным автоматом;
  трёхстоечное шасси с пружинами, тормозами и рулением носовой стойкой, посадка на фюзеляж и на воду, разрушение;
  масса и центровка от топлива и бомб; гидравлика; детерминированный ГПСЧ и хэш состояния.
- ИИ-пилот: автопилот (ПИД) и полёт по кругу «взлёт → круг → посадка».
- Тесты: лётная огибающая (максимальная и крейсерская скорость, потолок, сваливание), отказ двигателя и флюгирование,
  детерминизм, бюджет тика, взлёт-круг-посадка в Алезани; покрытие ядра ~97%.
- Web Worker + Comlink, клиент Three.js: процедурный рельеф Корсики, море, полоса, временная модель B-25J
  (надпись и код, слот `nose_art`), кабина пилота с приборами в исторических единицах, внешний вид в «Учебном» режиме,
  клавиатура по разделу 12, автоснижение качества при FPS < 45.
- Таблицы `theatres`, `aircraft_types`, `airframes`; `SyncSimContent` и `php artisan sim:sync`; сидер загружает
  Корсику, B-25J и борт 43-4064. Страница `/training/{station}` (этап 1 — пилот).

### Added — этап 0, каркас
- Laravel 13 + официальный стартовый кит Vue (Inertia 3, Fortify: регистрация, подтверждение email, 2FA, passkeys).
- Docker Compose: nginx, php-fpm (PHP 8.4), reverb, horizon, scheduler, vite, postgres 17, redis 7, SeaweedFS (S3), mailpit.
- Reverb + Laravel Echo (`@laravel/echo-vue`), presence-канал `diagnostics`, событие `RadioCheck`,
  страница `/diagnostics/realtime`, E2E-тест «событие и whisper доходят до двух браузеров».
- Horizon, Filament 5 (`/admin`: только роль admin с подтверждённой 2FA, вход через Fortify).
- Пользователи: `locale`, `role` (player / moderator / admin, check-ограничение), `settings` JSONB.
- `pilot_profiles`: позывной (уникален без учёта регистра), звание, счётчики, предпочтительное место.
  Профиль создаётся при регистрации.
- Перечисление `Station` — 8 рабочих мест B-25J.
- i18n: `lang/{ru,en}.json`, `useI18n()`, тест на расхождение ключей.
- Пароли — argon2id; лимитер `api` 120/мин на пользователя.
- Качество: Pint, Larastan 8, ESLint (границы симядра, запрет `Math.random`), vue-tsc, Pest 4 (+ arch), Vitest, Playwright.
- CI GitHub Actions: lint → тесты (PHP 8.4 и 8.5) → E2E на docker compose; Renovate.
- Документы: ADR-0001 (авторитетный хост), ADR-0002 (vite-plus + ESLint), ADR-0003 (SeaweedFS вместо MinIO),
  допущения, todo, реестр ассетов, схема БД.
