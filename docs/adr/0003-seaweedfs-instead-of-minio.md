# ADR-0003: SeaweedFS вместо MinIO в dev-окружении

- Статус: принято
- Дата: 2026-11-04

## Контекст

ТЗ (раздел 4) указывает «S3-совместимое хранилище (MinIO в dev)». На 2026-11-04 образы
`minio/minio` и `minio/mc` недоступны на Docker Hub (`pull access denied`), а `quay.io/minio/*`
требует авторизации: MinIO прекратил публикацию открытых сборок.

## Решение

Сервис `s3` в `compose.yaml` — SeaweedFS (`chrislusf/seaweedfs`, Apache-2.0) с S3-шлюзом на порту 9000.
Ключи задаются в `docker/s3/s3.json`, бакет `b25j` создаёт одноразовый `s3-init` (`amazon/aws-cli`).
Приложение работает через стандартный драйвер `s3` Laravel (`AWS_ENDPOINT`, path-style), поэтому
в продакшене подставляется любое S3-совместимое хранилище без изменения кода.

## Альтернативы

- RustFS — ближе к MinIO по интерфейсу, но проект моложе.
- Garage — требует ручной раскладки кластера даже для одного узла.
- Собрать MinIO из исходников — поддержка своего образа ради dev-окружения.
