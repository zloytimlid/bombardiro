# ADR-0001: синхронизация с авторитетным хостом

- Статус: принято
- Дата: 2026-11-04

## Контекст

Игра кооперативная, до 8 игроков на одном самолёте. Бэкенд должен остаться целиком на PHP (Laravel),
отдельный игровой сервер на Node не нужен. Детерминизм симядра гарантирован только в пределах одного
JS-движка (`Math.sin` и др. расходятся между браузерами), поэтому lockstep ненадёжен.

## Решение

Один браузер экипажа (хост) считает симуляцию в Web Worker на 60 Гц. Остальные шлют ему ввод
(`client-input`) и получают снапшоты (`client-snap`, 15 Гц, ключевой кадр 1 Гц + дельты) через
client events (whisper) Laravel Reverb. Сервер хранит журнал событий, снапшоты для миграции хоста
(Redis, TTL 10 мин), считает разбор и проверяет правдоподобие результатов.

## Альтернативы

- **Авторитетный сервер на Node** — честнее, но второй бэкенд и стоимость CPU на каждый экипаж.
- **Авторитетный сервер на PHP (Octane)** — тик 60 Гц на PHP дорог; пересмотр только по нагрузочному тесту.
- **Lockstep** — минимальный трафик, но рассинхронизация из-за различий float-функций между движками.

## Последствия

- Хосту доверяем; рейтинги считаются только по сессиям, прошедшим серверную проверку (`VerifySession`).
- Нужны миграция хоста (≤ 3 с) и переподключение (место держится 120 с).
