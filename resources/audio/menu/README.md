# Музыка главного меню

Положите сюда файлы `.mp3`, `.ogg`, `.m4a` или `.wav` — меню подхватит их автоматически
(порядок перемешивается при каждом заходе, треки идут по кругу).

- Имя файла становится названием трека: `01-morning_patrol.mp3` → «morning patrol».
- Каждый трек запишите в `docs/assets.md`: источник, лицензия, атрибуция.
  Только свои треки или треки с открытой лицензией (раздел 1: защищённые ассеты запрещены).
- После добавления файла перезапуск не нужен в dev (Vite), для продакшена — `npm run build`.
