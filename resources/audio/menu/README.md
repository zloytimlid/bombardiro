# Музыка главного меню

Положите сюда файлы `.mp3`, `.ogg`, `.m4a` или `.wav` — меню подхватит их автоматически
(порядок перемешивается при каждом заходе, треки идут по кругу).

- Имя файла становится названием трека: `01-morning_patrol.mp3` → «morning patrol».
- Каждый трек запишите в `docs/assets.md`: источник, лицензия, атрибуция.
  Только свои треки или треки с открытой лицензией (раздел 1: защищённые ассеты запрещены).
- Список треков попадает во фронтенд при сборке, поэтому после добавления файла:
  - в разработке — перезапустить Vite: `docker compose restart vite` (папку он не отслеживает, чтобы не нагружать
    диск опросом);
  - в собранной версии (продакшен, временная ссылка) — пересобрать: `docker compose run --rm --no-deps vite npm run build`.
- Подчёркивание и дефис в имени становятся пробелами: апостроф пишите прямо в имени файла
  (`It's a Pair of Wings for Me.mp3`), иначе он пропадёт.
