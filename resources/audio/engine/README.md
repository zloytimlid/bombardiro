# Запись двигателей

Положите сюда файл `.mp3`, `.ogg`, `.m4a` или `.wav` с записью двигателей — игра возьмёт первый по алфавиту и будет
играть его петлёй на каждый мотор поверх синтеза (`resources/js/game/audio/engineSample.ts`). Без файла звучит
только синтез.

- Подойдёт и запись с пролётами: игра сама берёт самый ровный громкий участок 8 с, сглаживает шов петли и приводит
  громкость к общему уровню. Лучше всего — ровный гул на крейсерском режиме без голосов и музыки.
- Скорость воспроизведения следует оборотам: 1,0 при 2100 об/мин (`SAMPLE_REFERENCE_RPM`), от 0,35 до 1,45.
- Файлы в этой папке в репозиторий не попадают (`.gitignore`): права на записи — у их владельцев. Запишите источник
  и лицензию в `docs/assets.md`; публиковать сайт с чужой записью — только если лицензия это разрешает.
- Список файлов попадает во фронтенд при сборке: после замены файла — `docker compose restart vite` в разработке
  или `docker compose run --rm --no-deps vite npm run build` для собранной версии.
