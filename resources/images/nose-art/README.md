# Рисунок на носу (слот `nose_art`)

Положите сюда одну картинку `.png` или `.webp` с прозрачным фоном (примерно 600 × 500 px) — её подхватит модель
B-25J в игре и в главном меню. Только собственный рисунок или с лицензией заказчика; персонаж Li'l Abner
не воспроизводится. Запись об ассете — в `docs/assets.md`.
